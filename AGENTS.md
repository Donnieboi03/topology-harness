# Agent guidance

1. **Doctrine lives here** — atoms, compounds, sticky, routing, stubs, gates.
2. **This is a policy package, not a runtime** — hosts own spawn/resume/chat/tools.
3. **Do not invent host paths** — no product checkouts, home directories, or personal session ids in docs or code defaults.
4. **Roles:** Main → Orchestrator → TT. Prefer those names in prose; `topic_owner` / `leaf` are API aliases only.
5. **Host helpers:** prefer `host_model_block` / `for_host_telegram`; `hermes_*` names are aliases.
6. **Cost:** never claim the graph is always cheaper; measure on the host.
